# Endpoint security matrix

Generated by `python -m evals.endpoint_matrix --write` from the application's real routes. Limits are read from the code; authentication details, sensitivity and abuse consequences are declared in `evals/endpoint_matrix.py` and a test fails if a route is not classified.

**Limiter storage:** SQLite file in the data dir; survives restart; shared by processes on this machine; NOT shared between machines. **Distributed across machines: NO.** Survives process restart: yes. Counted per client IP (`X-Forwarded-For` ignored unless `TRUST_PROXY=1`).
