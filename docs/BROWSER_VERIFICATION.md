# Browser verification record

Generated by `python browser-tests/make_report.py` from the JSON files Playwright wrote during actual runs against the real Next.js frontend and an isolated backend (temporary encrypted data, stubbed paid provider, every real credential blanked).

**Reproduce:** `cd browser-tests && npm install && npx playwright test` (Edge, default). Others: `PFI_BROWSER=chrome`, `PFI_BROWSER=firefox` (after `npx playwright install firefox`), add `PFI_MOBILE=1` for a 390x844 touch viewport. Ports 3100 and 8100 must be free. Then `python make_report.py`.

## Not covered by any browser run
WebKit/Safari (no WebKit run was made; Safari behaviour is untested), real phones (the mobile run is viewport and touch EMULATION in a desktop engine), the print/PDF view, accessibility checks, payment flows, the real try-on provider (always stubbed), slow-network behaviour.
